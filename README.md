# Neue² Dojo on Hyperfy

| Folder | World | Live copy |
| --- | --- | --- |
| `neue2dojo/` | **[hyperfy.io/neue2dojo](https://hyperfy.io/neue2dojo)**: Neue² Dojo Gallery (`world-1194`) | https://decentralize-dfw.github.io/neue2dojo-world/neue2dojo/ |
| `dfw/` | **[hyperfy.io/dfw](https://hyperfy.io/dfw)**: element / design / store (`world-288`) | https://decentralize-dfw.github.io/neue2dojo-world/dfw/ |

The site's root, https://decentralize-dfw.github.io/neue2dojo-world/, opens Neue² Dojo.

All of DFW's copied worlds are listed in [theaters/WORLDS.md](https://github.com/decentralize-dfw/theaters/blob/claude/serene-feynman-iuoz5y/WORLDS.md).

This repository uses the same tools as [decentralize-dfw/theaters](https://github.com/decentralize-dfw/theaters); its README describes them in full. The GitHub Pages site runs each world entirely in the browser, with Hyperfy's own client and game server (npm packages `hyperfy-client`, `hyperfy-server`, `hyperfy-api`, `hyperfy-router` 2.40.0, MIT). Each world folder holds every file its world uses, stored under the same paths it has on Hyperfy's servers, plus `manifest.json` (every mirrored file with its source URL, size and sha256) and `world.json`.

## Adding a world

Requires Python 3 and Node.js 18 or newer:

```sh
npm install
python3 tools/hyperfy_mirror.py --slug <slug> --out <folder>
echo '{"modes": []}' > <folder>/site.json
# add the folder to "worlds" in pages.json
npm run build:pages
```

GitHub Pages sites are limited to 1 GB. With Neue² Dojo and element / design / store the site takes about 530 MB.

## Running a world with Node

```sh
npm install
npm start                    # Neue² Dojo: http://localhost:4000/neue2dojo
WORLD=<folder> npm start
```

## Layout

| Path | Contents |
| --- | --- |
| `<world>/api.hyperfy.io/`, `data.hyperfy.xyz/`, `hyperfy.io/`, `fonts.gstatic.com/` | The mirrored world: record, component code and assets |
| `<world>/manifest.json`, `world.json`, `site.json` | File list with hashes, parsed scene, and mode buttons |
| `<world>/index.html`, `env.js` | The world's page, generated by `npm run build:pages` |
| `client/`, `local/`, `cdn.jsdelivr.net/`, `d3js.org/`, `vjs.zencdn.net/` | Shared by all worlds' pages; generated |
| `index.html`, `404.html` | Site root: opens the first world; sends unknown paths back to their world |
| `pages.json` | The site's URL and its worlds |
| `site/`, `server/`, `tools/` | Sources for the Pages site, the Node server and the mirror/build tools |
